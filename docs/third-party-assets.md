# Third-party assets

Everything in the site that AutoX did not make itself, where it came from, and the terms it
is used under. Code dependencies are in `package.json` and `backend/pom.xml`; this file is
for the assets copied into the repository.

given because it is right to, not because it is required.

Taken from Commons rather than Unsplash for the licence. Photos uploaded to Unsplash
before mid-2017 were published under CC0, and Commons keeps that licence on record with each
file. Unsplash's later licence also permits this use, but it is Unsplash's own and is
recorded nowhere outside Unsplash. If the photo is replaced, keep to CC0 or an equally
plain licence, and update this section.

The photo is decorative (`alt=""`) and shown under a navy gradient.

## Icons — Lucide

| | |
|---|---|
| Files | `frontend/src/app/shared/ui/icons.data.ts`, generated by `frontend/scripts/icons.mjs` |
| Source | `lucide-static` 1.59.0, https://lucide.dev |
| Licence | ISC, plus MIT for the icons Lucide inherited from Feather (notices below) |

The icon shapes are copied in as data, not installed: the site uses about twenty-five of
Lucide's icons, and `scripts/icons.mjs` explains how to add one. Of those in use,
`arrow-right`, `calendar`, `chevron-down`, `search` and `x` are among those Lucide lists as
derived from Feather.

## What is deliberately not here

- **Manufacturers' logos.** They are trademarks. The home page names makes in text only.
- **Any other site's branding, photos or wording.** The home page follows the usual layout of
  a French car marketplace, but its colours, wordmark, copy and imagery are AutoX's own or
  listed above.
